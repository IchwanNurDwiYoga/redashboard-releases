# ReDashboard

Dashboard PC desktop modern untuk **Windows 10 / 11** dengan pemantauan sistem real-time, kontrol media & lirik tersinkronisasi, Game Hub, Code Workspace, Folder Favorit, dan sistem tema musiman.

## Unduh Versi Terbaru

👉 **[Download ReDashboard Installer (Latest Release)](https://github.com/IchwanNurDwiYoga/redashboard-releases/releases/latest)**

## Fitur Utama

- **System Monitoring** — CPU, RAM, GPU, storage, jaringan, uptime, dan informasi perangkat.
- **Media & Lirik** — integrasi Windows Now Playing (GSMTC), visualizer spektrum audio, dan lirik tersinkronisasi.
- **Game Hub & Code Workspace** — deteksi game (Steam, Epic, Xbox, Battle.net), statistik sesi, serta pelacakan aktivitas coding harian.
- **Catatan, Jadwal & Kalender** — to-do/jadwal, cuaca lokal (Open-Meteo), fase bulan/matahari, dan Kalender Hijriah Global Tunggal (KHGT).
- **Backup & Restore** — ekspor/impor pengaturan JSON selektif dan auto-backup lokal otomatis.
- **Pembaruan Terintegrasi** — cek dan pasang versi terbaru langsung dari halaman *Settings → Tentang ReDashboard*.

## Persyaratan Sistem

- Windows 10 atau Windows 11 (64-bit)
- Tidak memerlukan instalasi Python terpisah

## Instalasi & Pembaruan

1. Unduh file `ReDashboard-Setup-x.y.z.exe` dari halaman [Releases](https://github.com/IchwanNurDwiYoga/redashboard-releases/releases/latest).
2. Jalankan installer dan ikuti petunjuk hingga selesai.
3. Seluruh pengaturan, catatan, shortcut, dan statistik disimpan lokal di `%APPDATA%\ReDashboard`, sehingga proses upgrade ke versi baru tidak menghapus data Anda.

## Privasi

ReDashboard berjalan secara lokal di perangkat Anda dan tidak mengirimkan data telemetri.
